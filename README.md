# Hardcoded-Hunter
Hardcoded Hunter je rychlý multiplatformní nástroj napsaný v jazyce Rust s grafickým rozhraním postaveným na knihovně egui. Pomocí paralelního zpracování (multithreading přes worker pool) dokáže efektivně prohledávat zdrojové kódy a detekovat nebezpečně zakodované hodnoty (hardcoded řetězce a cesty).
